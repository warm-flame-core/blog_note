# 移位操作符
移位操作符针对的是一个整数的储存在内存中的数据，即反码。
## 左移操作符`<<`
左移操作符的符号是`<<`。其规则是：**左边抛弃，右边补0。**例如如果想让10的反码左移一位，就可以写成：
```c
int num = 10;
int n = num << 1;
```
其中，10的移位结果传给了`n`，`num`的结果还是`10`。如果想要修改num的结果可以写成：

- num = num << 1;

或者是简便写法：

- num <<= 1;

## 右移操作符
右移运算其实分为两种：

 1. 逻辑右移：左边用0填充，右边扔掉
 2. 算术右移：左边用符号位数值填充，右边丢弃
 
 其中大部分编译器用的是算数右移。具体表示方式与上文的左移操作符类似，不再赘述。
# 位操作符
 位操作符有四种：按位与`&`、按位或`|`、按位异或`^`、按位取反`~`
 下面所有举例都是四个二进制位，是为了方便展示，实际上整形储存是4个字节，即32个二进制位
 
## 按位与
按位与操作符接受两个操作数在内存中储存的数据进行比较，其规则是：**对应位如果都是`1`，则输出`1`，其余情况都为`0`。**

```c
	int n = 3;
	int m = 5;
	printf("%d\n", n & m);
	return 0;
//       0011
//       0101
//结果为:0001
```
## 按位或
按位或操作符接受两个操作数在内存中储存的数据进行比较，其规则是：**只要对应位有`1`就输出`1`，其余情况都为`0`。**

```c
	int n = 3;
	int m = 5;
	printf("%d\n", n | m);
	return 0;
//       0011
//       0101
//结果为:0111   , 即为7
```
## 按位异或
按位异或操作符接受两个操作数在内存中储存的数据进行比较，其规则是：**对应位上数字相同为`0`，不同为`1`。**

```c
	int n = 3;
	int m = 5;
	printf("%d\n", n ^ m);
	return 0;
//       0011
//       0101
//结果为:0110   , 即为6
```
## 按位取反
按位异或操作符接受`一`个操作数在内存中储存的数据进行比较，其规则是：**对应位上的数字0->1、
1->0**

```c
	int n = 3;
	int m = 5;
	printf("%d\n", ~m);
	return 0;
//       0101
//结果为:1010 ,是负数，转为原码是-6
```
# 移位操作符与位操作符的实际运用
## 不创建第三个的变量，交换两个变量的数据
根据之前的介绍，我们可以得出一些运算结论，在按位异或中：
自反性：a ^ a = 0（相同数异或，所有位都相同，结果为 0）；
归零性：a ^ 0 = a（任何数异或 0，所有位不变，结果为自身）；
交换律：a ^ b = b ^ a；
结合律：(a ^ b) ^ c = a ^ (b ^ c)；
可逆性：a ^ b ^ b = a（异或两次同一个数，恢复原值）
我们就可以运用可逆性交换两个变量的值：

```c
int a = 10, b = 20;
    printf("交换前：a=%d, b=%d\n", a, b);
    
    a = a ^ b; // 第一步：a = 10^20
    b = a ^ b; // 第二步：b = (10^20)^20 = 10
    a = a ^ b; // 第三步：a = (10^20)^10 = 20
 
    printf("交换后：a=%d, b=%d\n", a, b);
```
## 按奇偶分别输出一个数在内存中储存的二进制
同样的在按位与中：
`n = n & (n-1)`能把n的二进制序列中最右边的1去掉，我们可以不去掉但是打印出来，去让`n`右移`i`位之后与`1`做`按位与`运算就可以把`n`的二进制序列的第`i`位提取出来

```c
#include <stdio.h>
int main()
{
	int n = 0;
	scanf("%d", &n);
	printf("奇数位是：");
	int i = 0;
	for (i = 31; i >= 1; i -= 2)
	{
		printf("%d", (n >> i) & 1);
	}
	printf("\n");
	printf("偶数位是：");
	int j = 0;
	for (j = 30; j >= 0; j -= 2)
	{
		printf("%d", (n >> j) & 1);
	}
	return 0;
}
```
