## 一，hello world程序示例

```c
#include <stdio.h>
int main()
{
	printf("hello world");
	return 0;
}
```
~~好像哪个编程语言开始学的时候都是打印这句话(＠_＠;)~~ 
这段代码表示在屏幕上显示`hello world`这句话。其中`#include<stdio.h>`叫头文件；`main`是一个函数；`printf("hello world");`是一条语句

### **可能的问题**
程序的输出可能在屏幕上一闪而过？某些窗口环境会在单独的窗口运行程序，然后在程序运行结束后自动关闭窗口，可以试试在`return`语句前面加一句代码：

```c
getchar();
```
这行代码会让程序等待按键，按下后才会继续下一步操作。

### **示例解释**
1. `#include`：预处理器指令
2. `int main`：总是被第一个调用的函数
	- `printf`：执行打印语句。
	- `return`：函数返回值
**此示例的运行顺序为从上至下**
## 二，main函数
C语言中，无论有多少行代码，多少个函数，程序的入口都是`main`函数。***所以一个项目里有且只有一个`main`函数***，即一个项目有多个.c文件，也只有一个`main`函数，因为程序的入口只有一个。

> `main`函数前面的`int`表示函数执行结束之后要返回一个整形类型的值，和`return 0;`正好前后呼应。

## 三，库函数
试想一下如果要开发一个十分常见的功能，那么不同程序员会用不同的方法，那么不仅非常耗时，而且没有不可移植。C语言标准就规定了一些常用的功能，把一些功能整合成一个标准，编译器厂商就会根据标准设计一些函数库，即`标准库`.标准库里的函数就是`库函数`。
使用标准库里的函数的时候就要先写出包含的库。就是`头文件`。在本篇的示例中就是:

```c
#include<stdio.h>
```
标准库多种多样，其他标准库详见：[C语言头文件](https://cplusplus.com/reference/clibrary/)
但是并非所有库函数都能满足需求，有的时候我们需要自己写库函数，那么引用自己的库就是：

```c
#include "XXXXX.h"
```

> **所以在代码的开头需要写出这个程序所包含的库函数对应的头文件。**

## 四，关键字
C语言中有一些字符是有实际意义的，程序员不能随便创建和使用在本例中就是`int`，`return`
	- 关键字不能自己创建。
	- 关键字不能作为变量或者常量。
	- 关键是给C语言用的，不是给你用的。
常见的关键字如下：

```c
 auto  break   case  char  const   continue  default  do   double else  enum   extern 
float  for   goto  if   int   long  register    return   short  signed  sizeof static 
struct  switch  typedef union  unsigned   void  volatile  while
```
这是老师说的参见的关键字，当然还有其他的，先把常用的记下来就可以了
详细其他的关键字可以见：[关键字](https://en.cppreference.com/w/c/keyword)
## 五，转义字符
有的时候需要打印多行字符，比如每行都需要一个`hello world`。这样每次打印完一行就需要换行。可以这样实现：

```c
#include <stdio.h>
int main()
{
	printf("hello world\n");
	printf("hello world\n");
	printf("hello world\n");
	return 0;
}
```
这里的`\n`就是表示换行，放在双引号后面。成为`转义字符`。常见的转义字符还有：
- `\'`：⽤于表⽰字符常量'
-  `\"`：⽤于表⽰⼀个字符串内部的双引号
- `\\`：⽤于表⽰⼀个反斜杠，防⽌它被解释为⼀个转义序列符。
- `\a`：警报，这会使得终端发出警报声或出现闪烁，或者两者同时发⽣。
- `\b`：退格键，光标回退⼀个字符，但不删除字符。
- `\f`：换⻚符，光标移到下⼀⻚。在现代系统上，这已经反映不出来了，⾏为改成类似于
- `\n`：换⾏符。
- `\r`：回⻋符，光标移到同⼀⾏的开头。
- `\t`：制表符，光标移到下⼀个⽔平制表位，通常是下⼀个4/8的倍数。
- `\v`：垂直分隔符，光标移到下⼀个垂直制表位，通常是下⼀⾏的同⼀列
此外转义字符可以但是使用不需要接在字符串后面，***但是一定要用双引号***。
## 六，字符和字符串和\0
### 字符
在键盘上能按出来的符号就叫`字符`，**在C语言中字符用单引号括起来**，就像`'a'`   `'b'`
但是在计算机里数据用二进制储存的，我们需要对每个字符进行编码，即给每个字符一个标号，常见的标准就是**ASCII编码**，如下表所示：
![ASCII编码](https://i-blog.csdnimg.cn/direct/ab14cb2187bf457e9e1ec746091ca650.png)
详细可见：[ASCII编码](https://en.cppreference.com/w/cpp/language/ascii)。不需要全部记住，有一些记一下：
 - 字符A~ Z的ASCII码为65~90
 - 字符a~ z的ASCII码为97~122
 - 大小写英文字母差值为32
 - 0~9的ASCII码为48 ~57
 - 0~31的是不可打印字符，是用来执行某些操作的
### 字符串
C语言中用双引号括起来的就是`字符串`。在示例中`hello world`就是字符串
### \0
C语言中字符串末尾自动会添加`\0`表示字符串终止，在VS2022中可以打开监视，设置断点，运行示例的代码，打开监视：
![监视窗口](https://i-blog.csdnimg.cn/direct/086067837d514b49830b6b04ff0294be.png)
会发现最后一个是`\0`。\0表示一个字符串终止的标识，如果用一些手段不出现\0打印字符串，那么字符串将不会终止，之后的字符将会是随机字符。
## 七，占位符
还是以示例的代码，有的时候我们可以需要快速修改字符串的部分信息，比如不想对世界打招呼了，对人打招呼，那么修改的时候就会比较麻烦，这个时候我们可以这样写：

```c
	printf("hello %s", "人");
```
其中`%s`是占位符，表示某个地方先用一个符号占个位置，后面再替换他，表达式第二个参数就是要替换的字符。当然，占位符可以用多个，比如：

```c
printf("%s says it is %d o'clock\n", "lisi", 21);
```
输出就是

> lisi says it is 21 o'clock

常见的占位符有：

> `%a`：⼗六进制浮点数，字⺟输出为⼩写。 
> `%A`：⼗六进制浮点数，字⺟输出为⼤写。 
> `%c`：字符。//char
> `%d`：⼗进制整数（有符号的10进制整数）。//int 
> `%e` ：使⽤科学计数法的浮点数，指数部分的e为⼩写。
> `%E`：使⽤科学计数法的浮点数，指数部分的E为⼤写。
>  `%i`：整数，基本等同于%d。 
>  `%f`：⼩数（包含float 类型和double类型）。float-%f         double-%lf 
> `%g`：6个有效数字的浮点数。整数部分⼀旦超过6位，就会⾃动转为科学计数法，指数部分的e为⼩写。
> `%G`：等同于%g，唯⼀的区别是指数部分的E为⼤写。 
> `%hd`：⼗进制shortint类型。
> `%ho`：⼋进制shortint类型。
> `%hx`：⼗六进制shortint类型。 
> `%hu`：unsignedshortint类型。 
> `%ld`：⼗进制longint类型。
> `%lo`：⼋进制longint类型。 
> `%lx`：⼗六进制longint类型。 
> `%lu`：unsignedlongint类型。
> `%lld`：⼗进制longlongint类型。 
> `%llo`：⼋进制longlongint类型。
> `%llx`：⼗六进制longlongint类型。 
> `%llu`：unsignedlonglongint类型。
> `%Le`：科学计数法表⽰的longdouble类型浮点数。 
> `%Lf`：longdouble类型浮点数。
> `%n`：已输出的字符串数量。该占位符本⾝不输出，只将值存储在指定变量之中。 
> `%o`：⼋进制整数。 
> `%p`：指针（⽤来打印地址）。
> `%s`：字符串。 
> `%u`：⽆符号整数（unsignedint）。 
> `%x`：⼗六进制整数。 
> `%zd`：size_t 类型。
> `%%`：输出⼀个百分号。

这些也不用全部记下来，要用的时候查一下就是了。
