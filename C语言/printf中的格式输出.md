# printf
在之前的介绍中介绍了printf打印数值，但是在实际运用中，输出的数值往往要规定格式。下面以占位符方式为例，介绍如果规定格式。
<p align="center"><font color="red"><b>为了更好的展现输出格式，接下来的示例输出都会在输出的开始和结束加`|`字符用于区分</b></font></p>

## 限定占位符的最小宽度

### 整数情况
printf中可以限定最小的输出宽度，示例如下：

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%5d", 456);
	printf("|");
	return 0;
}
```
输出为

> |  456|

示例中的`%d`中间的`5`表示占位符宽度至少为5位。如果不满5位，那么就在前面加空格。输出的值是**右对齐**，如果希望左对齐，在输出内容后面添加空格，那么在示例中`5`前面添加`负号`。

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%-5d", 456);
	printf("|");
	return 0;
}
```
输出为：

> |456  |
### 小数情况
同样的，对于小数这个限定符是限定所有数字的最小显示宽度。示例如下：

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%10f", 3.14);
	printf("|");
	return 0;
}
```
输出为：

> |  3.140000|

注意小数点也是算一位。
## 总是显示正负号
默认情况下，打印函数不显示正数的符号，只显示负数的符号。如果想无论正负数都显示符号就在`%`后面加一个`+`。

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%+d", 3);
	printf("|");
	return 0;
}
```
输出为：

> |+3|

## 限定小数位数
限定小数位数和限定最小显示宽度是两个概念，前者是保留小数位数，后者是至少会显示的数字个数。
输出小数时，有时候想要限定一些小数位数，想要限定`x`位小数，在占位符`f`前面加上`.x`就可以，最小保留位数会***四舍五入***

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%.4f", 3.14159);
	printf("|");
	return 0;
}
```
输出为：

> |3.1416|

这种写法也可以与限定宽度占位符一起使用：

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%6.2f", 0.5);
	printf("|");
	return 0;
}
```
输出为：

> |  0.50|

上面示例中`%6.2f`表示输出字符最小宽度为6，小数位数为2。
### 另外的写法
最小宽度和小数位数两个限定值，都可以用`*`代替，用参数传入，如：

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%*.*f", 6, 2, 0.5);
	printf("|");
	return 0;
}
```
输出为：

> |  0.50|

## 输出部分字符串
`%s`时输出字符串的占位符，默认有多少输出多少，如果想要控制输出的字符数，用`%.X s`,其中`X`为输出的长度，如下例：

```c
#include<stdio.h>
int main()
{
	printf("|");
	printf("%.5s", "hello world");
	printf("|");
	return 0;
}
```
结果为：

> |hello|

# 结语
以上这些用法互相结合，在比赛和实际运用中都有妙处
